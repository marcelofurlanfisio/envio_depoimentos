# envio_depoimentos

Formulário para alunos enviarem depoimentos sobre os cursos do Prof. Marcelo Furlan.

- `index.html`, página do formulário. Os envios vão para o Apps Script ligado à planilha "Depoimentos dos cursos" e chegam com status Pendente.
- `fotos/depoimentos/`, fotos de perfil dos alunos aprovados, com o nome do arroba (exemplo `ana.silva.jpg`). O nome do arquivo também vai na coluna "Foto (arquivo)" da planilha.

Link geral: https://marcelofurlanfisio.github.io/envio_depoimentos/

Link por curso, com o curso já marcado, usando `?curso=` e um destes códigos: `mobilizacao-neural`, `tmm-coluna`, `tmm-membros-atm`, `liberacao-miofascial`, `pos-graduacao`, `outro`.

Exemplo: https://marcelofurlanfisio.github.io/envio_depoimentos/?curso=liberacao-miofascial
